  # API de Vendas

Projeto focado em cadastro de produtos e registrar venda com base em todos os produtos escolhidos, assim facilitando a gestão de vendas

## Sumário

* [Principais Funcionalidades](#principais-funcionalidades)
* [Tecnologias Utilizadas](#tecnologias-utilizadas)
* [Contato](#contato)

## Principais Funcionalidades

* **[Criar um usuário]:** função de criar um usuário por meio de email e senha
* **[CRUD de um produto]:** função de criar, editar, excluir e ler um produto criado por um usuário específico
* **[CRUD de uma venda]:**  função de criar, editar, excluir e ler uma venda que contenha produto(s)
* **[Cálculo de vendas]:** função que cálcula a quantidade de produtos dentro de uma venda realizada

## Tecnologias Utilizadas

* **[Linguagem de Programação]** (C-sharp)
* **[Framework/Biblioteca]** (Dotnet, .NET 10 e Scalar)
* **[Banco de Dados]** (SQL Server)
* **[Outras Ferramentas]** (Git/Github)
